Native Claude Code Lifecycle Hooks

Toggle Claude Code hooks on in Settings and Better Rich Presence listens locally on loopback for live agent events—even when another window is in focus.

  • Localhost only Listens strictly on 127.0.0.1:47892 without blocking Claude Code.
  • Privacy-first Shows active action, filename, and project folder—never full paths, shell args, or prompts.
  • One-click setup Safely updates ~/.claude/settings.json and disconnects cleanly anytime.
~/.claude/settings.json 127.0.0.1:47892 
// Added automatically by Settings → Connect
{
  "listener": "http://127.0.0.1:47892/hooks/claude-code",
  "shows":    ["action", "project", "optional chat title"],
  "redacts":  ["full paths", "shell args", "prompts"]
}

  • Native Win32 APIs: Instant foreground window title, executable, and idle detection with zero polling bloat.

Linux

  • Multi-compositor support: X11 (_NET_ACTIVE_WINDOW), GNOME Wayland (D-Bus / Window Calls + Mutter IdleMonitor), Hyprland (hyprctl), Sway (swaymsg), plus process-scan fallback.

FAQ

Frequently Asked Questions

Straight technical answers on detection, privacy, OS support, and resource usage.

How does Better Rich Presence detect my apps and programming languages?

Better Rich Presence monitors the active window using native OS APIs (Win32 on Windows; X11, GNOME Wayland, Hyprland, and Sway on Linux) and matches it against 280+ pre-configured apps. For code editors like VS Code, it parses the open filename from the window title and displays the matching programming language icon on Discord automatically.

How does the Claude Code integration work, and is it private?

In Settings, click Connect to register local HTTP lifecycle hooks in ~/.claude/settings.json pointing strictly to 127.0.0.1:47892. Better Rich Presence displays only the current action, project folder name, and optional chat title on Discord—never full file paths, shell arguments, or prompt contents.

Does Better Rich Presence work on both Windows and Linux?

Yes. Windows ships with an NSIS installer using native Win32 window and idle APIs. Linux ships as .deb, .rpm, and .AppImage packages with native support for X11, GNOME Wayland, Hyprland, Sway, a process-scan fallback, system tray controls, and XDG login autostart.

How much RAM and CPU does it actually use?

Because the background core is written in Rust with Tauri 2 instead of Electron, Better Rich Presence typically runs under 20 MB of RAM and under 0.2% CPU, with a ~4 MB binary that starts in under a second.

Do I need a Discord Developer Portal application or custom tokens?

No. Better Rich Presence connects directly to your local Discord desktop client over Discord IPC with zero developer portal setup, no tokens, and no mandatory accounts.

Is Better Rich Presence free and open source, and can I add my own app?

Yes. Better Rich Presence is 100% free and MIT-licensed on GitHub. You can add any custom executable right inside the Apps tab, or submit a pull request adding one entry to apps.json so everyone gets out-of-the-box support.
