What is Discord Rich Presence, and how do you get it?

Discord Rich Presence is the activity card on your Discord profile that shows what you are doing, such as "Playing" a game, with a title, a short status line, an icon, and a timer. Games and apps that support it set it for you; for any other app you can get a custom Rich Presence for free by running Better Rich Presence, which detects your app and updates the card automatically on Windows and Linux.

What Discord Rich Presence is

Rich Presence, also called an "Activity" in Discord's own documentation, is the current activity of a user. Other people see it in several places on Discord:

  • Your user profile.
  • Friend lists.
  • Server member lists.

The classic example is a game: your profile says what you are playing, what you are doing in it, and for how long. The card is built from a few fields:

Field What it shows
Name The game or app name, shown on your profile.
Details The main line, such as what the player is doing.
State A secondary status line.
Timestamps Elapsed or remaining time.
Assets Artwork and small icons, such as a game thumbnail or a badge.
Not the same as Discord Activities Discord's documentation separates Rich Presence from Discord Activities, which are embedded games. This guide is about Rich Presence, the status card on your profile.

How Rich Presence normally works

The app or game has to tell Discord what to display. Developers do that with Discord's Social SDK, or by talking to a running Discord desktop client through RPC (Remote Procedure Call). The app must be registered with Discord and have an Application ID. Discord's reference for this is the Setting Rich Presence page, kept in this project's docs.

That means a game has Rich Presence only if its developer built it in. For everything else, such as a code editor, a design tool, a terminal, or a browser, you need a separate tool that sets the presence for you. That is what people mean by custom Rich Presence or a custom RPC.

Desktop client required Discord's documentation says Rich Presence via RPC only works with a running Discord desktop client. It does not support mobile, console, or web clients.

How to get Rich Presence for any app

Better Rich Presence is a free, open-source desktop app that does the RPC work for you. It watches the focused window and updates your Discord status automatically, with no Developer Portal application and no token. It ships with a catalog of 280+ pre-configured apps, so most apps work as soon as you run it.

Step 1: Download it

Open the latest release on GitHub and pick the build for your system. On Windows that is the NSIS installer. On Linux it is a .deb, .rpm, or .AppImage package.

Step 2: Run it with Discord open

Keep the Discord desktop app running, then start Better Rich Presence. When it reaches Discord, the colored band at the top of the window reads Live on Discord. Make sure the Share switch is on.

Step 3: Open the app you want to show

Switch to a supported app, for example VS Code, Figma, Blender, Spotify, or Docker. The Now tab shows a What friends see preview of the card Discord displays, so you can check it without leaving the app.

Step 4: Pick what owns your presence

The Apps tab has two modes:

  • Dynamic follows the window you are using.
  • Priority List keeps your highest-ranked running app shown.

You can reorder the list, switch any app off, and customize the details and state text per application. To keep it running after a restart, turn on Start on login in Settings.

Add an app that is not listed (custom RPC)

If your app is not in the catalog, you can still set up a custom RPC in a minute. Open the Apps tab, click Add App, and enter the app's executable or its window title. Check the Now tab to confirm the card. The full walkthrough is in the custom app guide.

Code editors get one extra detail: Better Rich Presence reads the open file name from the window title and shows the matching programming language icon, with 90+ languages and special files covered. See the VS Code guide for an example.

Privacy: who sees it and how to turn it off

Anyone who can see your Discord profile, friend list, or a server member list you appear in can see your Rich Presence, so think about what it reveals before you leave it on all day. You are in control of it:

  • The Share switch pauses or resumes presence instantly.
  • Any app in the Apps tab can be switched off so it never appears on your profile.
  • Better Rich Presence connects to your local Discord client over Discord IPC. The project states there is no telemetry and no accounts, and the source is on GitHub under the MIT License.

If nothing shows up

  • Not connected to Discord. Start or restart the Discord desktop app. The web and mobile apps do not work for this.
  • Sharing off. Turn the Share switch back on.
  • Paused for a game. Discord detected a game, and Better Rich Presence yields to it. Your game owns the presence for now.
  • Your app is missing. Add it from the Apps tab, or open an issue on GitHub.

FAQ

Is Discord Rich Presence free?

Yes. Rich Presence is a Discord feature, and Better Rich Presence is free and open source under the MIT License, with no paywalls, no telemetry, and no accounts.

Does Discord Rich Presence work on mobile or in a browser?

No. Discord's own documentation says Rich Presence set through RPC only works with a running Discord desktop client, and it does not support mobile, console, or web clients. Better Rich Presence is a Windows and Linux desktop app, so you need a computer with the Discord desktop app open.

Is it safe, and who can see it?

Rich Presence shows on your Discord profile, friend list, and server member lists, so anyone who can see your profile can see it. Better Rich Presence connects to your local Discord client over Discord IPC, needs no token or account, and is open source. You can pause everything with the Share switch or turn off any single app.

Do I need a Discord Developer Portal application or a token?

No. Normally an app has to be registered with Discord and use an Application ID, but Better Rich Presence already handles that. It connects directly to your local Discord desktop client over Discord IPC, with no Developer Portal setup, no token, and no account to create.

How do I get a custom Rich Presence for an app that has none?

Use a custom RPC tool. In Better Rich Presence, check the built-in catalog of 280+ apps in the Apps tab first, and if your app is missing, click Add App and enter its executable or window title. The custom app guide walks through it.
