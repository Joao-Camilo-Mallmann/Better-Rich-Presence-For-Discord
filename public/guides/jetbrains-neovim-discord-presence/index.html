Discord Rich Presence for JetBrains, Neovim, Zed, Sublime Text, and Cursor

Better Rich Presence shows JetBrains IDEs, Neovim, Zed, Sublime Text, and Cursor on your Discord profile without a plugin: it watches the focused window and matches it against a built-in catalog of 280+ apps. For code editors it also reads the open file name from the window title and adds a programming language icon, so a Rust file and a TypeScript file get different badges. It is free, open source, and runs on Windows and Linux.

What you need

  • A Windows or Linux computer.
  • The Discord desktop app, running. Better Rich Presence talks to it locally over Discord IPC.
  • One of the editors below. Nothing has to be installed inside the editor itself.
No plugin, no Developer Portal Better Rich Presence watches the focused window from outside your editor. There is no JetBrains plugin, no Neovim plugin, and no Discord Developer Portal application, token, or account to create.

Step 1: Install Better Rich Presence

Open the latest release on GitHub and download the build for your system. On Windows that is an NSIS installer. On Linux pick the .deb, .rpm, or .AppImage package. The VS Code guide walks through the install in more detail, and the Linux guide covers the supported compositors.

Step 2: Open your editor and check Discord

Start Better Rich Presence. When it reaches Discord, the colored band at the top of the window reads Live on Discord. Open your IDE, Neovim, Zed, Sublime Text, or Cursor and a file. The Now tab shows a What friends see preview, so you can confirm the result without leaving the app.

Switching windows does not make your status flicker: transitions are debounced, so a quick Alt-Tab does not rewrite your presence.

Step 3: How the language icon is chosen

For code editors, Better Rich Presence parses the open file name from the window title and looks up the language. The icon set covers 90+ languages and special files. The documented examples include main.rs for Rust, App.tsx for TypeScript and React, and special files such as Cargo.toml and Dockerfile. Other icons you will see include:

  • TypeScript
  • JavaScript
  • Python
  • Go
  • C++
  • C#
  • Java
  • Kotlin
  • Lua
  • Zig
  • Swift
  • Svelte
  • Vue
  • Nix

The project documents language badges for Cursor, the JetBrains IDEs IntelliJ IDEA, PyCharm, WebStorm, and CLion, Neovim, Zed, and Sublime Text.

Keep the file name in the title Detection reads the window title, so the open file name has to be visible there. If your editor is set up to hide it, the language icon cannot be matched.

Step 4: Using more than one editor

If you move between, say, an IDE for one project and Neovim for another, the Apps tab decides which one owns your presence.

  • Dynamic mode follows the window you are using.
  • Priority List mode keeps your highest-ranked running app shown, so your main editor stays on your profile while you check other windows.
  • Reorder the list, switch any app off, or customize the details and state text per application.

The Share switch in the status band pauses or resumes presence instantly. To keep the app running after a restart, turn on Start on login in Settings.

Troubleshooting

The status band at the top of the app tells you what is happening.

Band says What it means What to do
Live on Discord Connected and sharing. Open a file in your editor and check the Now tab.
Sharing off The Share switch is off. Turn Share back on.
Paused for a game Discord detected a game, and the app yields to it. Nothing. Your game owns the presence for now.
Connecting to Discord or Not connected to Discord The app cannot reach the Discord desktop client. Start or restart the Discord desktop app.

If the status is live but the language icon is missing, make sure the editor is the focused window and its title shows the file name. If the application itself is missing from the list, you can add it as a custom app: see the custom app guide, or open an issue on GitHub.

FAQ

Do I need a plugin for JetBrains IDEs, Neovim, Zed, or Sublime Text?

No. Better Rich Presence reads the focused window and its title with native OS APIs, so nothing is installed inside your editor. It matches the window against a catalog of 280+ apps and parses the open file name from the title to pick the language icon.

Which JetBrains IDEs are in the built-in catalog?

IntelliJ IDEA, PyCharm, WebStorm, PhpStorm, RubyMine, CLion, GoLand, Rider, DataGrip, and Android Studio.

Why is the language icon missing in my editor?

Detection reads the window title, so the open file name has to be visible there. Make sure the editor is the focused window and its title shows the file name. If the app itself is missing, you can add it as a custom app.

How do I keep my main editor on Discord while I use other windows?

Switch the Apps tab to Priority List mode and rank your editor first. Better Rich Presence then keeps your highest-ranked running app shown, instead of following whichever window is in focus.
