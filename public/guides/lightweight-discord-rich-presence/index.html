Lightweight Discord Rich Presence: why it stays under 20 MB of RAM

Better Rich Presence typically runs under 20 MB of RAM and under 0.2% CPU because its core is written in Rust with Tauri 2, which uses your operating system's WebView instead of bundling a Chromium instance. The binary is about 4 MB and it starts in under a second. This guide explains each piece of that design: the native core, native window and idle detection, debounced updates, and the tray.

The numbers

These are the typical figures published by the project for the background app:

Measure Better Rich Presence Typical Electron app
Memory Under 20 MB (about 18 MB) About 180 MB
Idle CPU Under 0.2% About 4.5%
Binary size About 4 MB About 80 MB
Cold startup Under 1 second About 5 seconds
How to read these figures They are approximate values from the project's own landing page, not a lab benchmark. The Electron column is a generic reference point for an app that bundles Chromium. Your numbers depend on your machine.

Rust core, Tauri 2 shell

The background engine is written in Rust. The window you see is a small React 19 interface, built with the React Compiler, that runs in your operating system's WebView through Tauri 2. That is where the size difference comes from: there is no Chromium instance inside the app, only a thin native layer.

Native window and idle detection

Better Rich Presence asks the operating system which window is focused and matches it against its catalog of 280+ apps.

  • Windows: native Win32 APIs return the foreground window title, the executable, and idle time.
  • Linux: X11 active window hints, GNOME Wayland through D-Bus, and Hyprland and Sway through hyprctl and swaymsg. If none is available, a process scan matches your enabled rules by priority. See the Linux guide.

Idle detection is native too. When you step away, the app updates your status automatically instead of keeping the last app on your profile. On Windows it uses the Win32 idle APIs. On Linux, X11 reads idle time through Mutter or xprintidle, and GNOME Wayland uses Mutter IdleMonitor.

Debounced updates stop flicker

Switching windows quickly could send a burst of presence updates to Discord. Better Rich Presence debounces the transitions, so a quick Alt-Tab does not rewrite your status. The result is a stable presence for your friends, and the project credits native OS window queries with debounced Discord IPC updates for the low idle CPU.

Games stay in charge When Discord detects a game, the app yields to it, and the status band reads Paused for a game. The project describes the CPU cost as having zero game impact.

Lives in the tray

A presence app should stay out of your way. On Windows, the NSIS installer does a single-user install and adds a system tray icon. On Linux, there is a system tray menu to reopen or quit the app. Turn on Start on login in Settings and the app starts with the --minimized flag, quietly in the tray.

The Share switch in the status band pauses or resumes your presence instantly, without closing the app.

Catalog and icons are data, not code

The 280+ apps are entries in a JSON file, apps.json, each with a process name, a category, and an icon URL. Adding an app is one new entry, not new detection code. The 300 full-color icons are 512x512 PNGs that live in the repository. The interface renders the icon URL directly, and for Discord the Rust engine rewrites it to a CDN URL. If an app has no icon, it sends a default key instead. You can read the details in the icon documentation.

No accounts, no tokens

The app connects to your local Discord desktop client over Discord IPC. There is no Developer Portal application, no token, no mandatory account, and no telemetry. It is open source under the MIT License, so you can read the code that runs in your tray on GitHub. The Rust backend follows Clean Architecture, and the architecture rules are in the contributing guide.

FAQ

How much RAM does Better Rich Presence use?

Better Rich Presence typically runs under 20 MB of RAM and under 0.2% CPU, with a binary of about 4 MB that starts in under a second.

Why is it so much lighter than an Electron app?

Its core is written in Rust with Tauri 2, which uses your operating system's WebView instead of bundling a Chromium instance. That keeps both the binary and the memory footprint small.

Will it slow down my games?

The idle CPU use is under 0.2%, because the app uses native OS window queries and debounced Discord IPC updates. When Discord detects a game, the app also yields to it.

Does it run in the background without a window?

Yes. It runs in the system tray on Windows and Linux. With Start on login turned on, it launches minimized at login.
