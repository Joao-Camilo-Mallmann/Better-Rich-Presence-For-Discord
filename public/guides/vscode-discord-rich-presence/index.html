How to show VS Code on Discord (with language icons)

To show VS Code on Discord with language icons, install Better Rich Presence, keep the Discord desktop app open, and open a file in VS Code. The app detects the focused VS Code window, reads the file name from its title, and puts the matching programming language icon on your Discord profile. It is free, open source, runs on Windows and Linux, and needs no Discord Developer Portal setup.

What you need

  • A Windows or Linux computer.
  • The Discord desktop app, running. Better Rich Presence talks to it locally over Discord IPC.
  • VS Code or VS Code Insiders. Both are in the built-in catalog of 280+ apps.
Nothing to configure in VS Code There is no extension to install and no Discord Developer Portal application, token, or account to create. Better Rich Presence watches the focused window from outside the editor.

Step 1: Install Better Rich Presence

Open the latest release on GitHub and download the build for your system.

Windows

Download the installer (NSIS) and run it. Windows detection uses native Win32 window and idle APIs.

Linux

Pick the .deb, .rpm, or .AppImage package. Detection supports X11, GNOME Wayland, Hyprland, and Sway, with a process-scan fallback. Compositor details are in the Linux guide.

Build from source (optional)

The project is MIT licensed. You need Bun (or Node.js 18+) and Rust, plus the Tauri prerequisites for your OS.

git clone https://github.com/Joao-Camilo-Mallmann/Better-Rich-Presence-For-Discord.git
cd Better-Rich-Presence-For-Discord
bun install
bun run tauri dev

Step 2: Open VS Code and check Discord

Start Better Rich Presence. When it reaches Discord, the colored band at the top of the window reads Live on Discord. Now open VS Code and a file. The Now tab shows a What friends see preview, so you can check the result without leaving the app.

Switching windows does not make your status flicker: the app debounces transitions, so a quick Alt-Tab does not rewrite your presence.

Step 3: How the language icon is chosen

Better Rich Presence matches the focused window against its app catalog. For code editors it then parses the open file name from the window title and looks up the language. The icon set covers 90+ languages and special files, for example:

  • main.rs shows the Rust icon.
  • App.tsx shows a TypeScript and React icon.
  • Cargo.toml and Dockerfile are recognized as special files.

Other icons you will see include:

  • TypeScript
  • JavaScript
  • Python
  • Go
  • C++
  • C#
  • Java
  • Kotlin
  • Lua
  • Zig
  • Swift
  • Svelte
  • Vue
  • Nix
Keep the file name in the title Detection reads the window title, so the file name has to be visible there. If you changed VS Code's title format to hide it, the language icon cannot be matched.

Step 4: Choose what Discord shows

The Apps tab controls which application owns your presence.

  • Dynamic mode follows the window you are using.
  • Priority List mode keeps your highest-ranked running app shown, so VS Code stays on your profile while you check a browser.
  • Reorder the list, switch any app off, or customize the details and state text per application.
  • The Share switch in the status band pauses or resumes presence instantly, and idle detection updates your status when you step away.

To keep the app running after a restart, turn on Start on login in Settings.

Troubleshooting

The status band at the top of the app tells you what is happening.

Band says What it means What to do
Live on Discord Connected and sharing. Open a file in VS Code and check the Now tab.
Sharing off The Share switch is off. Turn Share back on.
Paused for a game Discord detected a game, and the app yields to it. Nothing. Your game owns the presence for now.
Connecting to Discord or Not connected to Discord The app cannot reach the Discord desktop client. Start or restart the Discord desktop app.

If the status is live but the language icon is missing, make sure VS Code is the focused window and its title shows the file name. A missing language or app can be added: see the custom app guide, or open an issue on GitHub.

FAQ

Do I need a VS Code extension to show VS Code on Discord?

No. Better Rich Presence reads the focused window and its title with native OS APIs, so nothing is installed inside VS Code. It matches the window against a catalog of 280+ apps and parses the open file name from the title to pick the language icon.

Do I need a Discord Developer Portal application or a token?

No. Better Rich Presence connects directly to your local Discord desktop client over Discord IPC. There is no Developer Portal setup, no token, and no account to create.

Does it work with editors other than VS Code?

Yes. The built-in catalog covers VS Code Insiders, Cursor, Windsurf, Zed, Neovim, Sublime Text, and the JetBrains IDEs such as IntelliJ IDEA, PyCharm, WebStorm, and CLion. Language icons work in the editors that show the open file name in their window title.

Does it work on Linux as well as Windows?

Yes. Windows uses native Win32 detection. Linux supports X11, GNOME Wayland, Hyprland, and Sway, with a process-scan fallback when no focused-window backend is available.

How much memory and CPU does it use while I code?

Better Rich Presence typically runs under 20 MB of RAM and under 0.2% CPU, because its core is written in Rust with Tauri 2 instead of Electron.
