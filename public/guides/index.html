Guides

Discord Rich Presence guides for developers

Better Rich Presence is a free, open-source desktop app that shows what you are working on in Discord, with language icons for your editor and live Claude Code status. Each guide answers one question, step by step.

  • Show VS Code on Discord Install the app, open a file, and get a language icon on your profile. Read the guide
  • Claude Code Discord status Show your live Claude Code session as your Discord status, with one-click setup. Read the guide
  • Discord Rich Presence on Linux What works on X11, GNOME Wayland, Hyprland, and Sway, and the fallback when nothing does. Read the guide
  • Add any app Create a custom Rich Presence rule without touching the Discord Developer Portal. Read the guide
  • JetBrains, Neovim, Zed, Sublime, Cursor Language icons and presence for the other editors and IDEs you use. Read the guide
  • Lightweight Rich Presence Why a Rust and Tauri core stays under 20 MB of RAM. Read the guide
