How to show your Claude Code session as a Discord status

To show your live Claude Code session as your Discord status, open Better Rich Presence, go to Settings, and click Connect in the Claude Code section. The app registers local HTTP lifecycle hooks in your Claude Code settings file, then puts what Claude Code is doing, such as “Running command”, and the project folder name on your Discord profile. It is free, open source, runs on Windows and Linux, and never sends full paths, shell arguments, or prompt text.

What you need

  • A Windows or Linux computer with Claude Code installed.
  • The Discord desktop app, running. Better Rich Presence talks to it locally over Discord IPC.
  • Better Rich Presence from the latest release on GitHub.
No Developer Portal, no token There is no Discord Developer Portal application, token, or account to create. Claude Code reports to a small receiver inside Better Rich Presence, and the app talks to your local Discord client.

Step 1: Connect Claude Code

Open Better Rich Presence and switch to the Settings tab. In the Claude Code section, click Connect. You do not edit any JSON by hand: the app adds its hooks to ~/.claude/settings.json (or $CLAUDE_CONFIG_DIR/settings.json if you set that variable) without overwriting the rest of the file.

Once connected, the section shows a Live state, the config file it changed, and the listener address. The button turns into Disconnect, which removes the integration cleanly whenever you want.

The receiver listens strictly on 127.0.0.1:47892, the loopback address, so nothing leaves your machine, and it does not block Claude Code while it works.

Step 2: What Discord shows

Start a Claude Code session and your profile updates with the live state of that session:

  • The current action, for example Running command.
  • The project folder name, for example trailer. It is the folder name only, not the full path.
  • An optional chat title, which you can switch off.
  • The file name Claude Code is working on, when there is one.

The Now tab shows a What friends see preview of this card, plus a Claude Code chats panel. It lists each active chat and marks the one currently being shown on Discord.

What is never shown

Shown on Discord Never shown
The active action Full file paths
The project folder name Shell arguments
The chat title, if you leave it on Prompt text

Two switches in the same Settings section control the rest. Show active sessions keeps your live Claude Code session on Discord even when another window is in focus. Show chat title on Discord decides whether the active chat title is included. If your chat titles describe private work, turn the second one off.

Save your changes Settings has a Save changes button at the bottom. Switch the options you want, then save.

Step 3: Set the inactivity timeout

Minutes before timeout sets how long the app waits after Claude Code goes quiet. When that time passes, it switches back to normal app detection, so your status follows the window you are using again instead of staying on an idle session. The screenshot above shows the field set to 5 minutes. Use a lower value to hand the status back quickly, and a higher one if you often pause while reading output.

Step 4: Claude Code priority over other apps

Claude Code is a rule in the Apps tab like any other app, so you decide where it ranks. In Priority List mode, the highest running app in the list is shown, and Claude Code shows only over the apps ranked below it. Rank it first, as in the screenshot, and your Claude Code session wins over VS Code, Cursor, and the rest while it is running. Use the arrows to reorder, or the switch to turn any app off.

Dynamic mode follows the focused window instead. Keep Show active sessions on if you want a live Claude Code session visible while you work in another window.

Claude and Claude Code are separate entries The built-in catalog lists the Claude desktop app and Claude Code as two apps. The hooks described here drive the Claude Code entry.

Troubleshooting

Check the status band at the top of the app first.

Symptom What to check
Band says Connecting to Discord or Not connected to Discord Start or restart the Discord desktop app.
Band says Sharing off Turn the Share switch back on.
Band says Paused for a game Discord detected a game and the app yields to it. Nothing to fix.
Claude Code does not appear Confirm Settings shows Live, Show active sessions is on, and no app ranked above Claude Code is running in Priority List mode.
The chat title is missing Turn on Show chat title on Discord and save.
Status went back to another app The inactivity timeout passed. Raise Minutes before timeout if you want it longer.

FAQ

Does Better Rich Presence show my prompts or file paths on Discord?

No. It shows only the current action, the project folder name, and an optional chat title. Full file paths, shell arguments, and prompt text are never sent to Discord.

Do I have to edit Claude Code settings by hand?

No. Click Connect in the Claude Code section of Settings and the app registers its hooks in ~/.claude/settings.json (or $CLAUDE_CONFIG_DIR/settings.json) without overwriting the rest of the file. Click Disconnect to remove them.

Does the integration slow down Claude Code or send data online?

No. The receiver listens strictly on 127.0.0.1:47892, so events stay on your machine, and it does not block Claude Code. The app talks to your local Discord client over Discord IPC.

What happens when I stop using Claude Code?

After the number of minutes set in Minutes before timeout, the app switches back to normal app detection and your status follows the window you are using.

Can I hide the chat title?

Yes. Turn off Show chat title on Discord in the Claude Code section of Settings, then save. The action and project folder name are still shown.
