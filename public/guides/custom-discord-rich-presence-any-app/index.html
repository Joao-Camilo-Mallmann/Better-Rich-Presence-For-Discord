How to add any app to Discord Rich Presence without the Developer Portal

To add any app to Discord Rich Presence, open the Apps tab in Better Rich Presence, click Add App, and enter the app's executable or window title. No Discord Developer Portal application, token, or account is needed, because the app talks to your local Discord desktop client over Discord IPC. It is free, open source (MIT), and runs on Windows and Linux.

What you need

  • A Windows or Linux computer with Better Rich Presence installed.
  • The Discord desktop app, running.
  • The app you want to show, so you can check its executable name or window title.
No Developer Portal, no tokens The usual way to get custom Rich Presence is to create an application in the Discord Developer Portal and write code against it. Better Rich Presence skips that: it connects directly to your local Discord client, so adding an app is a form in the Apps tab, not a project.

Step 1: Check the built-in catalog

Better Rich Presence ships with a catalog of 280+ pre-configured apps, defined in apps.json. It covers code editors, terminals, Docker, databases, browsers, Figma, Blender, Obsidian, and media tools. Open the Apps tab and use the search box, which filters both your enabled rules and the ones available to turn on. If your app is already there, switch it on and you are done.

Step 2: Add your app

If the app is not in the list, add it yourself:

  1. Start the app you want to show, so it is running.
  2. In Better Rich Presence, open the Apps tab and click Add App.
  3. Enter the app's executable or its window title.
  4. Check the Now tab. Its What friends see preview shows the card Discord will display.

Use whichever of the two identifies the app better. For reference, the catalog lists lowercase process names and includes both the Windows and the Linux name, for example code.exe and code. Matching ignores case and a trailing .exe.

Step 3: Choose Dynamic or Priority List

Once you have several apps, the mode at the top of the Apps tab decides which one owns your presence.

Mode What Discord shows Good for
Dynamic The app in focus, updating as you switch windows. A status that mirrors what you are doing right now.
Priority List Your highest-ranked running app. Keeping your editor on your profile while you check other windows.

A tooltip in the app explains each mode. Transitions are debounced, so a quick Alt-Tab does not rewrite your status.

Step 4: Reorder, toggle, and customize

  • Reorder: change the rank of a rule with one click. In Priority List mode, rank decides which app wins.
  • Toggle: switch any app off and it stops appearing on your profile.
  • Customize: set the details and state text per application.
  • Share switch: pause or resume presence instantly from the status band.

Better Rich Presence also yields automatically when Discord detects a game, and it updates your status when it detects you are idle.

Per-app text Each category in the catalog (for example editor, browser, or media) decides the default presence text for its apps. Per-application customization lets you change that wording for a single app.

Step 5: Add it for everyone through apps.json

A rule you add in the Apps tab is yours. If the app is popular, add one entry to apps.json so every user gets it out of the box. The contributing guide describes the format. Each entry has these fields:

Field Meaning
id Unique lowercase identifier, for example epicgames.
name Display name shown in the app and in Discord.
executables Lowercase process names to match, with the Windows and Linux names.
client_id Discord application ID. Reuse the one every other entry uses.
category One of the categories already in the file. It decides the presence text.
icon_url URL of the PNG in public/assets/icons/. Optional but strongly recommended.

The steps are short:

  1. Copy a similar entry in apps.json and edit it, keeping the file's formatting.
  2. Add a 512x512 transparent PNG icon and point icon_url at it. Icons are generated from theSVG logos with npm run assets:generate -- --only <name>.
  3. Run the app, open the target application, and check that the Apps tab and the status preview show it.
  4. Open a pull request.
Icons arrive after the merge Icons appear in Discord only after the pull request is merged to main and the CDN cache refreshes. Logos are trademarks of their owners and are used only to identify the running application.

Catalog entries and icons can skip the planning process used for larger changes. Open an issue first only if you are unsure the change fits.

Troubleshooting

  • The status band is not Live on Discord. Make sure the Discord desktop app is running and the Share switch is on.
  • Paused for a game. Discord detected a game, and Better Rich Presence yields to it.
  • Your app does not appear. Make sure its rule is switched on. In Dynamic mode the app has to be the focused window. In Priority List mode it has to be running and rank above the others.
  • Wrong or missing app. Open the Now tab to see what Discord would display, then adjust the executable or window title of the rule.

For editors, the file name also has to appear in the window title to get a language icon. See the VS Code guide and the JetBrains, Neovim, Zed, Sublime, and Cursor guide.

FAQ

Do I need a Discord Developer Portal application to add a custom app?

No. You add a custom executable or window title in the Apps tab, and Better Rich Presence connects to your local Discord desktop client over Discord IPC. There is no Developer Portal setup, no token, and no account to create.

How do I add an app that is not in the built-in catalog?

Open the Apps tab, click Add App, and enter the executable or the window title of the app. If you want everyone to get that app out of the box, submit a pull request that adds one entry to apps.json.

What is the difference between Dynamic mode and Priority List mode?

Dynamic mode follows the app in focus as you switch windows. Priority List mode keeps your highest-ranked running app shown in Discord. You pick the mode at the top of the Apps tab, and a tooltip explains each one.

Can I reorder apps, switch one off, or change its presence text?

Yes. In the Apps tab you can reorder the priority list, toggle any app off, and customize the details and state text per application. A search box filters your enabled and available rules.
